# 📥 IT Script Generator - Installation Guide

## For Team Members

### 🚀 Quick Install (3 Steps)

#### Step 1: Download
Go to: **https://github.com/vlad9976/IT-app/releases/latest**

Click on: `IT-Script-Generator-Setup-X.X.X.exe`

#### Step 2: Install
1. Run the downloaded `.exe` file
2. Choose where to install (or use default)
3. Click "Install"
4. Wait for installation to complete

#### Step 3: Launch
- Find "IT Script Generator" in Start Menu
- Or use desktop shortcut
- That's it! 🎉

## 🔄 Updates

**You don't need to do anything!**

The app checks for updates automatically:
- Every 4 hours in the background
- Downloads updates silently
- Prompts you to restart when ready

When you see this notification:

```
✅ Update ready! Restart to install?
   [Restart Now] [Later]
```

Just click "Restart Now" - takes 5 seconds!

## ❓ Troubleshooting

### Can't download?
- Make sure you're logged into GitHub
- Contact admin for repository access

### Installation fails?
- Run as Administrator
- Disable antivirus temporarily
- Contact IT support

### App won't launch?
- Check Windows version (requires Windows 10+)
- Restart your computer
- Reinstall the app
